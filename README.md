# Автоматизация обработки отчётов о продажах (ETL на Python)

## О проекте

Разработан Python-скрипт для автоматического объединения ежедневных CSV-отчётов о продажах из нескольких магазинов в единый структурированный набор данных.

**Цель проекта:** исключить ручную обработку файлов, отфильтровать посторонние данные и подготовить единый CSV-файл для дальнейшей аналитики.

## Бизнес-задача

Торговая сеть регулярно получает от магазинов файлы с данными о продажах. При этом:

- В общей папке могут находиться посторонние файлы.
- Названия файлов не всегда соответствуют установленному формату.
- В некоторых отчётах присутствуют лишние столбцы.
- Исходные CSV используют точку с запятой, а итоговый файл должен использовать запятую.

Необходимо автоматизировать обработку этих файлов и объединить корректные записи в один набор данных.

## Технологии

- **Python** — реализация алгоритма обработки.
- **glob** — поиск файлов в папке.
- **re** — проверка названий файлов регулярным выражением.
- **csv** — чтение и запись CSV.
- **os** — работа с путями и папками.

Решение реализовано без сторонних библиотек, включая pandas.

## Алгоритм обработки

1. Поиск CSV-файлов в исходной папке.
2. Отбор файлов по шаблону `YYYY-MM-DD-HH-MM-store_id.csv`.
3. Чтение подходящих файлов с разделителем `;`.
4. Проверка наличия обязательных столбцов.
5. Удаление лишних столбцов и приведение структуры к единому формату.
6. Последовательное объединение записей.
7. Сохранение результата в `combined_data.csv` с разделителем `,`.

Проверка календарной корректности дат в названиях файлов не выполняется в соответствии с условиями кейса.

## Структура итоговых данных

| Поле | Описание |
|---|---|
| `date` | Дата продажи |
| `product` | Идентификатор товара |
| `store` | Идентификатор магазина |
| `cost` | Стоимость продажи |

## Результаты

На учебном наборе данных:

- Найдено 13 CSV-файлов.
- По шаблону имени отобрано 6 файлов.
- Удалён лишний столбец `id` из одного отчёта.
- Объединено 30 записей о продажах.
- Получен итоговый CSV с четырьмя столбцами.

Результат первоначального решения успешно прошёл сравнение с эталонным набором данных в Google Colab.

## Запуск

Для запуска скрипта необходим Python 3. Сторонние библиотеки не требуются.

Разместите исходные CSV-файлы в папке `reports-main` рядом со скриптом и выполните:

```bash
python process_files.py
```

После выполнения в папке `comb_reports` появится файл `combined_data.csv`.

Для использования других папок можно импортировать функцию:

```python
from process_files import process_files

process_files("input_folder", "output_folder")
```

## Практическая ценность

Проект демонстрирует базовые этапы ETL-процесса:

- **Extract** — поиск и чтение исходных файлов.
- **Transform** — фильтрация, проверка и унификация данных.
- **Load** — сохранение объединённого набора данных.

Построчная обработка позволяет не загружать все исходные таблицы в память одновременно.
